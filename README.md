# Monstruido 🟢

### Un aula más tranquila, una aventura más divertida.

**Monstruido** es una plataforma educativa interactiva que busca fomentar la autorregulación del ruido dentro del aula mediante un monstruo virtual que reacciona al ambiente. Su objetivo es convertir el silencio y la convivencia en una experiencia divertida para los estudiantes.

🌐 **Aplicación web:** [https://monstruido-education-tbgx.bolt.host](https://monstruido-education-tbgx.bolt.host)

---

## 🎯 Objetivo del proyecto

Crear una herramienta digital que ayude a los docentes a promover ambientes de aprendizaje más tranquilos y participativos, utilizando elementos visuales e interactivos que motiven a los estudiantes a regular el ruido del salón.

## ✨ Secciones y funcionalidades

### 1. Inicio de sesión
Permite ingresar el nombre del usuario y asignar un nombre al monstruo para personalizar la experiencia desde el inicio.

### 2. Mi monstruo
Es la sección principal de la plataforma. El monstruo reacciona al nivel de ruido ambiental captado por el micrófono del dispositivo, mostrando diferentes emociones según el ambiente del aula.

### 3. Trivias
Permite crear actividades de preguntas y respuestas para reforzar el aprendizaje. El docente puede personalizar las preguntas, agregar imágenes y configurar diferentes opciones de respuesta. El monstruo también reacciona a las respuestas de los estudiantes.

### 4. Mi clase
Muestra información del comportamiento del ruido durante una sesión, mediante gráficas y estadísticas como duración, promedio, nivel máximo y porcentaje de tiempo en calma. También permite descargar los registros en formato CSV.

### 5. Personalidad
Permite personalizar características del monstruo y configurar mensajes motivacionales para las respuestas correctas e incorrectas de las trivias.

## 🤖 Prompt inicial del proyecto

El siguiente prompt fue utilizado como punto de partida para desarrollar la idea de Monstruido mediante inteligencia artificial:

<details>
<summary><strong>Ver prompt inicial</strong></summary>

Actúa como un experto en desarrollo web, diseño UX/UI y educación infantil.

Quiero crear una página web interactiva para ayudar a los niños a mantener el silencio en el salón de clases, utilizando un monstruo amigable que reaccione al ruido.

La página debe tener un diseño atractivo, divertido, moderno y fácil de utilizar para niños y docentes.

El monstruo debe cambiar de expresión dependiendo del nivel de ruido que detecte el micrófono. Debe tener diferentes estados emocionales, como feliz, triste, enojado, sorprendido y tranquilo.

La página debe incluir las siguientes secciones:

- **Mi monstruo:** mostrar al monstruo y permitir que reaccione al ruido ambiental.
- **Trivias:** permitir crear preguntas y respuestas para que los estudiantes puedan participar en actividades educativas.
- **Personalidad:** permitir personalizar al monstruo y sus mensajes.
- **Mi clase:** mostrar información y estadísticas del ruido registrado durante una sesión.

El diseño debe ser amigable, intuitivo y responsivo, con colores pastel y elementos visuales que transmitan diversión y tranquilidad.

La experiencia debe motivar a los niños a cuidar el ambiente del salón y comprender cómo sus acciones influyen en el bienestar de su monstruo.

## 🚀 Instalación y ejecución local

Si deseas ejecutar el proyecto localmente:

1. Clona este repositorio:

   ```bash
   git clone https://github.com/Betzy-1103/monstruido.git
   ```

2. Accede a la carpeta:

   ```bash
   cd monstruido
   ```

3. Instala las dependencias:

   ```bash
   npm install
   ```

4. Inicia el servidor de desarrollo:

   ```bash
   npm run dev
   ```
